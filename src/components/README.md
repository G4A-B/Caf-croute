# src/components

Composants d'interface réutilisables (bouton, carte de plan, étiquette de prix...).

Règles :
- styles avec les variables de `src/styles/tokens.css`, jamais de couleur en dur ;
- zone tactile d'au moins `var(--taille-tactile-min)` (44 px) ;
- textes en français, sans tiret cadratin.
